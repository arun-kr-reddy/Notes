## LeetCode Prep
- focus on pattern recognition rather than code memorization, *i.e.* can you solve new problems?
- **Solve Method:**
  - read problem twice & manually trace two sample inputs on paper
  - write pseudocode for brute force solution
  - identify bottlenecks and try to optimize
  - if cannot make any headway in 10 min, watch video solution, code it yourself & mark it for review
- **Short Notes:** intuition behind problem, new trick or core pattern, edge case, time & space complexity
  - ***e.g.*:** two sum
    |              |                                                                     |
    | ------------ | ------------------------------------------------------------------- |
    | intuition    | reframe `a+b=target` into searching for complement `b=target-a`     |
    | core pattern | hash-map for `O(1)` single pass complement lookups                  |
    | edge case    | duplicates (*e.g.* `3+3=6`), check map **before** inserting current |
    | complexity   | `O(N)` time & `O(N)` space                                          |
- retry marked problems (+ 1 new similar problem) on the 1st and 3rd weekends
- intial prep takes multiple months, but future refreshes will only take weeks
